# Background Audio Injector for GTA 3

A small ASI plugin I developed for my mod "Grand Theft Alone III" for the sole purpose of playing background music during gameplay. It hooks directly into HSTREAM in the Miles middleware without touching existing ambient audio streams or radio stations.

## Features
- Inject any audio of your choice directly into GTA 3
- One-time and loop playback
- Volume control
- Toggle audio on and off
- etc.

## Usage
Set your audio filepath and settings in AloneMusicPlayer.ini and run the game. Audio playback can be toggled on or off using the M key on your keyboard.

## Requirements
- GTA III v1.0
- Ultimate ASI Loader by ThirteenAG
